RestinPID 3.4

  • Needs Attention: apps that aren’t responding, and busy macOS apps, now gather in one group at the top of the list so you see them first. Prefer them at the bottom? Settings → Apps.
  • Cleaner rows: the “Not Responding” badge sits next to the app’s name, and RAM and CPU always stay on one line.
  • Fewer false alarms: an app is marked “Not Responding” only after it misses two checks in a row, so a single slow moment no longer flags it.
  • The arrow keys move through the list in the order you see it.
