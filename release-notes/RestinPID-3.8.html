RestinPID 3.8

  • Asks before it restarts or quits an app. Unsaved work in that app is lost, so this is now on by default. Turn it off in Settings → General.
  • Safer force quit: RestinPID checks it is still the same app before quitting it, including after you type an admin password.
  • If a restart or force quit fails, you now see a message saying so and what to try.
  • Restart tries again if the app doesn't open the first time.
  • Installer, Disk Utility and Migration Assistant are never restarted automatically.
  • Uses less energy: the glow and jiggle stop after 10 minutes. The red icon stays until you open the panel.
  • The app now includes its licence (MIT) and Sparkle's.
